# Logo v2 — 18/10/2026

Cambio solicitado por el propietario: simplificar el símbolo y usar fondo blanco, coherente con Facebook. Nueva versión; v1 conservada.

Generado con image_gen integrado (logo-brand), sin CLI. Prompt: símbolo simple y memorable de flecha ascendente redondeada con una hoja; verde #176b45 y acento #51ed7b, fondo blanco opaco, sin texto, negro, sombra o mockup; centrado con margen para círculo. El resultado tiene pequeñas variaciones tonales: no es un maestro vectorial ni acredita exclusividad de marca.

Un solo PNG versionado para encabezado/pie, favicon, Apple touch, perfil y vista previa. Dimensiones reales 1254×1254; no declarar tamaños inexistentes en HTML. El navegador reduce la imagen, sin modificar proporciones. Archivo de alrededor de 1 MB: optimización y maestro vectorial pendientes; no bloquean cambio visual solicitado.

Reversión: revertir el commit de esta versión restaura manifiesto, gate de sincronización, tokens e index. Ningún formulario, transporte o backend modificado.
