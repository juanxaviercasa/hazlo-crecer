## Flujo

Web → enlace con mensaje prellenado → el visitante decide enviar → conversación atendida por la empresa → solicitud con referencia si usa el formulario → revisión y plan → propuesta separada si decide implementar.

La web no envía mensajes por sí sola. Cambiar a WhatsApp Business no instala la API de Meta, un webhook ni un agente. Activar respuestas automáticas, horarios, etiquetas y mensajes de ausencia depende de las funciones disponibles en la cuenta y del horario que confirme el titular. No configurar mensajes de ausencia que prometan tiempos no acordados.
